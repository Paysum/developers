## Set it up

<Steps>
  <Step title="Open store settings">
    Choose the store in the dashboard switcher, then open Storefront → Settings.
  </Step>
  <Step title="Set your identity">
    Update the store name and description. Add a clear logo and favicon; a square image works well in small navigation and checkout areas.
  </Step>
  <Step title="Choose an accent">
    Use the color controls in onboarding or store customization. Check that text remains readable on buttons and selected states.
  </Step>
  <Step title="Review the result">
    Open your storefront and inspect the header, footer, product pages, and checkout on desktop and mobile.
  </Step>
</Steps>

## Use a public image

Images must be accessible to your visitors. A private cloud-drive page or a local file path is not a public image URL. If an image fails to load, open the URL in a private browser window and check that it displays the image directly.

## Branding is store-specific

Changing the selected store matters: each store has its own settings. Onboarding’s live preview reflects your unsaved choices; your public storefront reflects the settings you have actually saved.

## If something does not work

<Note title="What to check">
  If old branding appears, save the settings, reload the storefront, and check whether an applied custom theme overrides the default header or footer.
</Note>

Still stuck? [Contact support](https://docs.paysum.io/support) with the store, the page, and any order or request reference.
