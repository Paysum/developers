## Set it up

<Steps>
  <Step title="Create a coupon">
    Open Marketing → Coupons and add a code with a discount that fits the offer.
  </Step>
  <Step title="Set its limits">
    Review the expiry, usage limits, and any product or order requirements offered by the editor.
  </Step>
  <Step title="Save and try it">
    Open a checkout where the coupon is intended to work and apply the code.
  </Step>
  <Step title="Check the total">
    Confirm the final amount after selecting a payment method, including additional fees or discounts.
  </Step>
</Steps>

## Coupon scope

A code can be valid for one offer and invalid for another. Check its saved requirements before assuming a failed redemption is a checkout error.

## Share the right details

Tell buyers the code, what it applies to, and when it expires. Avoid distributing a permanent reusable discount when the offer is meant for a single campaign.

## API sessions

The creator of a hosted checkout session can disable coupons for that session. In that case, a store coupon does not override the session configuration.

## If something does not work

<Note title="What to check">
  Check spelling, expiry, usage limits, product requirements, and whether coupons were disabled for the checkout session.
</Note>

Still stuck? [Contact support](https://docs.paysum.io/support) with the store, the page, and any order or request reference.
