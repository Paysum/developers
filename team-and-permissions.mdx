## Set it up

<Steps>
  <Step title="Open Members">
    Go to Team → Members in the selected store.
  </Step>
  <Step title="Invite the collaborator">
    Send an invitation using the team screen and choose the access level or permissions you intend to grant.
  </Step>
  <Step title="Verify the invitation">
    Ask the collaborator to accept while signed into the intended account.
  </Step>
  <Step title="Review access regularly">
    Remove access that is no longer needed and check Security → Audit logs when investigating changes.
  </Step>
</Steps>

## Store access is scoped

Being a team member of one store does not automatically grant access to every store you own. Verify the active store when testing permissions.

## Separate human and API access

A collaborator’s dashboard permissions and a store API key’s permissions are separate. Avoid sharing your own account or a broadly scoped API key as a substitute for a team invitation.

## If something does not work

<Note title="What to check">
  If an invitation cannot be used, check its recipient, status, and the account currently signed in. If a page is inaccessible, review the member’s store permissions and plan availability.
</Note>

Still stuck? [Contact support](https://docs.paysum.io/support) with the store, the page, and any order or request reference.
