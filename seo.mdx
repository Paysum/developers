## Set it up

<Steps>
  <Step title="Set store metadata">
    Open the store’s SEO settings and write a useful title and description that describe what you sell.
  </Step>
  <Step title="Customize product metadata">
    Use each product’s SEO fields for specific titles, descriptions, and relevant keywords.
  </Step>
  <Step title="Choose a preview image">
    Use a publicly accessible image that still makes sense when cropped in a shared-link card.
  </Step>
  <Step title="Check the public URL">
    Open the published page and share its exact URL. Changes in search results and third-party preview caches are not immediate.
  </Step>
</Steps>

## Write for the page

A product title and description should describe that product rather than repeating the same keyword list across the whole catalog. Include information that helps a buyer decide whether the product meets their needs.

## Domains and redirects

Use the store’s current canonical domain consistently in shared links. When you connect a custom domain, review links in social profiles, descriptions, and advertising campaigns.

## Search visibility takes time

Saving metadata does not guarantee indexing, ranking, or an immediate new preview on an external platform. Check the rendered page first, then use that platform’s inspection or refresh tools if available.

## If something does not work

<Note title="What to check">
  A broken preview often comes from a private image URL, a redirect, or an external cache. Confirm the page and image can both be opened without signing in.
</Note>

Still stuck? [Contact support](https://docs.paysum.io/support) with the store, the page, and any order or request reference.
