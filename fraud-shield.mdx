## Set it up

<Steps>
  <Step title="Open Fraud Shield">
    Go to Security → Fraud shield for the selected store.
  </Step>
  <Step title="Review available rules">
    Use the rule types and limits shown by the dashboard. Start with a small set you can explain and monitor.
  </Step>
  <Step title="Check affected orders">
    Review the relevant logs or order outcomes after enabling a rule.
  </Step>
  <Step title="Adjust carefully">
    If legitimate customers are blocked, inspect the matching rule and evidence before broadly disabling protection.
  </Step>
</Steps>

## Rules work best with context

A single signal can be incomplete. Review the buyer, payment, product, and order details together rather than treating a risk signal as proof of wrongdoing.

## API and team access

Keep the ability to change protection settings limited to trusted team members. Review audit logs when a setting changes unexpectedly.

## If something does not work

<Note title="What to check">
  If an expected rule does not run, confirm it is enabled, available on your plan, and applies to the order being tested. For a blocked buyer, inspect which rule matched.
</Note>

Still stuck? [Contact support](https://docs.paysum.io/support) with the store, the page, and any order or request reference.
