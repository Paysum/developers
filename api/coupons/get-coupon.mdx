---
title: "Get coupon"
description: "Retrieves one coupon, including how often it has been used."
---

`GET /api/store-api/coupons/{coupon_id}`

Retrieves one coupon, including how often it has been used.

Permission: `coupons:read`

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `coupon_id` | path | string | yes | Coupon ID. |
