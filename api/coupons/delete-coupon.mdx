---
title: "Delete coupon"
description: "Permanently deletes a coupon."
---

`DELETE /api/store-api/coupons/{coupon_id}`

Permanently deletes a coupon.

Permission: `coupons:write`

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `coupon_id` | path | string | yes | Coupon ID. |
