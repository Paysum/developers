---
title: "List coupons"
description: "Lists coupons, newest first."
---

`GET /api/store-api/coupons`

Lists coupons, newest first.

Permission: `coupons:read`

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | integer | no | Number of results to return, between 1 and 100. |
| `offset` | query | integer | no | Number of results to skip. |
| `active` | query | boolean | no | Only active or inactive. |
