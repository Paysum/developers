`GET /api/store-api/orders`

Lists orders, newest first, each with its line items. Amounts are in the store currency. Page with `next_offset` rather than counting: keep passing it as `offset` until it is null.

Permission: `orders:read`

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `limit` | query | integer | no | Number of results to return, between 1 and 100. |
| `offset` | query | integer | no | Number of results to skip. |
| `status` | query | string | no | For example `completed`, `pending`, `expired` or `refunded`. |
| `email` | query | string | no | Exact customer email. |
| `created_after` | query | string | no | ISO 8601 time, inclusive. |
| `created_before` | query | string | no | ISO 8601 time, exclusive. |
