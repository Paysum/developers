---
title: "Get theme file"
description: "Reads one draft file."
---

`GET /api/store-api/theme/file`

Reads one draft file.

Permission: `themes:read`

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `path` | query | string | yes | Project path, for example `src/StorePage.tsx`. |
