`POST /api/store-api/products`

Creates a product in the key’s store. It appears on the storefront right away unless `is_active` is false, and fires the `product.created` webhook.

Permission: `products:write`

| Name | In | Type | Required | Description |
| --- | --- | --- | --- | --- |
| `title` | body | string | yes | Product name. |
| `price` | body | number | yes | Price in the store currency. |
| `description` | body | string | no | Shown on the product page. Markdown is supported. |
| `compareAtPrice` | body | number | no | Original price, shown struck through. |
| `category` | body | string | no | Category name. |
| `tags` | body | string[] | no | Search and filter tags. |
| `image` | body | string | no | Image URL, or a base64 data URL to upload. |
| `images` | body | string[] | no | Gallery images. |
| `stock` | body | integer | no | Units in stock. |
| `limited_stock` | body | boolean | no | Stop selling when `stock` reaches 0. |
| `use_product_keys` | body | boolean | no | Deliver one key from `digital_keys` per unit sold. |
| `digital_keys` | body | string[] | no | Keys to deliver. Never returned by the API; responses show `key_count`. |
| `max_per_order` | body | integer | no | Per-order quantity cap. |
| `is_active` | body | boolean | no | Listed on the storefront. |
| `is_featured` | body | boolean | no | Shown in featured sections. |
| `variants` | body | object[] | no | Variants with their own name, price and stock. |

```json
{
  "title": "Lifetime license",
  "price": 19.99,
  "use_product_keys": true,
  "digital_keys": [
    "AAAA-BBBB-CCCC",
    "DDDD-EEEE-FFFF"
  ]
}
```
