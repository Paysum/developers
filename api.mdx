The Paysum API is a JSON-over-HTTPS REST API. Requests and responses use `application/json`, timestamps are ISO 8601 strings in UTC, and amounts are plain numbers in the store’s currency.

## Store API

## OpenAPI specification

[Download the OpenAPI 3.1 specification](/openapi.json) to import the supported endpoints into your API client. It includes request parameters, permission requirements, and response examples from this reference.

<Note title="Public API and dashboard endpoints">
  A store API key can only call the endpoints documented here. Requests the dashboard makes in your browser are internal and are not available to keys.
</Note>

## Base URL

```bash
https://paysum.io
```

## Authentication

Send a store API key as a bearer token on every request. See [Authentication](https://docs.paysum.io/authentication) for permissions and key management.

```http
Authorization: Bearer sk_your_secret_key
```

## Pagination

List endpoints accept `limit` (1–100, default 20) and `offset` (default 0) and return the total alongside the page:

```json
{ "data": ["…"], "total": 42, "limit": 20, "offset": 0 }
```

[List orders](https://docs.paysum.io/api/orders/list-orders) returns `next_offset` instead of a total. Pass it as `offset` until it is `null`.
