## What the API covers

<p>The public API is organised by resource, each unlocked by its own key permission:</p>
<ul>
	<li>
		<strong>Store API</strong> - products, orders, customers, coupons and theme code for the store the
		key belongs to.
	</li>
	<li>
		<strong>Checkout sessions</strong> - create hosted checkouts for custom line items or products in
		your store, then track or cancel them.
	</li>
	<li>
		<strong>Withdrawals</strong> - read crypto wallet balances and send payouts to external addresses.
	</li>
	<li>
		<strong>Customer balance</strong> - look up customers and credit or debit their store balance.
	</li>
</ul>
<Tip title="Prefer the dashboard?">
	<p>
		Everything in the Guides tab can be done without code. The API is optional and only needed when
		you want to automate or embed Paysum in another product.
	</p>
</Tip>
