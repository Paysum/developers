## Set it up

<Steps>
  <Step title="Create categories">
    Open Catalog → Categories and group products by how customers look for them.
  </Step>
  <Step title="Use groups deliberately">
    Open Catalog → Groups when you need to organize related products beyond a single listing.
  </Step>
  <Step title="Build a bundle">
    Use Catalog → Bundles to configure the products and pricing that belong together.
  </Step>
  <Step title="Review add-ons">
    Open Catalog → Add-ons for optional extras. Test the product and checkout to see which extras are offered.
  </Step>
</Steps>

## Keep the choices understandable

Use names that describe the value a buyer receives. A bundle and a variant solve different problems: a variant changes an option on one product, while a bundle groups an offer.

## Check the whole offer

Review stock, delivery, product visibility, and final price for the complete selection. A bundle is only useful if each included item can be delivered correctly.

## If something does not work

<Note title="What to check">
  If an item is missing from the storefront, inspect its category assignment and active state, then check whether your current theme renders that catalog structure.
</Note>

Still stuck? [Contact support](https://docs.paysum.io/support) with the store, the page, and any order or request reference.
