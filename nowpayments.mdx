## Set it up

<Steps>
  <Step title="Copy your API key">
    In NOWPayments, open Store settings and copy the API key.
  </Step>
  <Step title="Generate an IPN secret">
    In the same settings, generate an IPN secret key. It is shown in full only once.
  </Step>
  <Step title="Connect in the dashboard">
    In the dashboard, open Payments → Payment setup → Cryptocurrency. Choose NOWPayments, paste both keys and select Connect.
  </Step>
  <Step title="Test with a small payment">
    NOWPayments’ sandbox is no longer maintained, so confirm the setup with a small real payment.
  </Step>
</Steps>

## When an order is paid

An order is paid when NOWPayments reports the payment as finished, meaning the funds reached your account. Underpayments stay pending for you to review.

## Minimum amounts

NOWPayments sets a minimum per coin, so very small orders may not offer every coin.

## If something does not work

<Note title="What to check">
  If orders stay pending, check that the IPN secret matches the one in NOWPayments and that your firewall doesn’t block NOWPayments’ notifications.
</Note>

Still stuck? [Contact support](https://docs.paysum.io/support) with the store, the page, and any order or request reference.
