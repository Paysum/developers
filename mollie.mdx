## Set it up

<Steps>
  <Step title="Copy an API key">
    In the Mollie dashboard, open Developers → API keys for the website profile you sell from. Copy the test_ key to try it out or the live_ key to take real payments.
  </Step>
  <Step title="Connect in the dashboard">
    In the dashboard, open Payments → Payment setup. Choose Mollie, paste the key and select Connect.
  </Step>
  <Step title="Activate payment methods">
    In Mollie, turn on the methods you want to offer. The buyer chooses one on Mollie’s checkout.
  </Step>
  <Step title="Place a test order">
    With a test_ key, Mollie’s test checkout lets you pick whether the payment succeeds, fails or expires.
  </Step>
</Steps>

## No webhook to set up

Mollie is told where to send updates with every payment, so there is nothing to paste into Mollie.

## Minimum amounts

Each Mollie method has its own minimum amount. Methods you activated can still be hidden on Mollie’s checkout for very small orders.

## If something does not work

<Note title="What to check">
  A test_ key keeps every payment in test mode. If a method is missing on Mollie’s checkout, check that it is activated for the same website profile as the key and that the order meets its minimum.
</Note>

Still stuck? [Contact support](https://docs.paysum.io/support) with the store, the page, and any order or request reference.
