## Set it up

<Steps>
  <Step title="Prepare the file">
    Give the file a recognizable name and confirm it opens correctly before offering it for sale.
  </Step>
  <Step title="Add the delivery link">
    Use the product editor’s file or download delivery option and save the link or file details requested by that screen.
  </Step>
  <Step title="Test access">
    Open the delivery destination in a private browser session. Check that it does not ask the buyer to sign into your personal storage account.
  </Step>
  <Step title="Place a test order">
    Confirm that the order delivery information leads to the intended file and version.
  </Step>
</Steps>

## Links and access

A cloud-storage sharing page may have different permissions from the actual download. Verify the buyer’s experience rather than relying on what works while you are signed in as the owner.

## Updates

When replacing a downloadable product, review its product description and delivery details together. Be clear about which version customers are buying and what support is included.

## If something does not work

<Note title="What to check">
  If customers receive an access-denied page, check the storage provider’s sharing permissions and whether the saved URL has expired or was replaced.
</Note>

Still stuck? [Contact support](https://docs.paysum.io/support) with the store, the page, and any order or request reference.
