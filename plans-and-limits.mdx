## Set it up

<Steps>
  <Step title="Check your current plan">
    Open the Premium page from the dashboard sidebar. Review the features included in your account before upgrading.
  </Step>
  <Step title="Look at the feature you need">
    Custom domains, team access, fraud controls, and other features can depend on the plan. A locked setting links to the relevant upgrade option.
  </Step>
  <Step title="Review pricing before confirming">
    Use the current pricing and checkout screens for the billed amount and renewal terms. Do not assume a quoted price from an older guide is still current.
  </Step>
</Steps>

## Store configuration and billing

A feature being available on your plan does not automatically configure it. After upgrading, return to the relevant dashboard page and finish its setup. Connecting your own domain still requires DNS configuration.

## API access is separately scoped

An API key also needs the correct permission for the operation. Upgrading a plan does not change an existing key’s permissions or remove the per-key rate limits documented in the API reference.

## If something does not work

<Note title="What to check">
  If a feature remains locked after a successful upgrade, refresh the dashboard and confirm you are signed into the account that purchased the plan. Include the payment reference when contacting support.
</Note>

Still stuck? [Contact support](https://docs.paysum.io/support) with the store, the page, and any order or request reference.
