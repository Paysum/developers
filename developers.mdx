## Keys and scopes

<p>
	Keys are created in <strong>Dashboard → Developers → API keys</strong>. Each key belongs to one store
	and carries scopes such as <code>products:read</code> or <code>themes:write</code>. A write scope
	includes the matching read scope. See <a href="https://docs.paysum.io/authentication">Authentication</a> for the
	full list.
</p>
